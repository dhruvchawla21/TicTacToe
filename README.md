# Tic Tac Toe 🎮

A simple command-line Tic Tac Toe game built using Python.

This project was created to practice basic programming concepts like:
- Functions
- Loops
- Conditionals
- Lists
- User input handling
- Game logic

---

## 🚀 Features

- Two-player gameplay
- Interactive terminal interface
- Win and draw detection
- Input validation
- Beginner-friendly code

---

## 🛠️ Technologies Used

- Python 3
