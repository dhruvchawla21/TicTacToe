Tic Tac Toe Game 🎮

A simple command-line Tic Tac Toe game built using Python.
This project was made to practice basic Python concepts like loops, functions, conditionals, lists, and user input handling.

🚀 Features
Two-player gameplay
Interactive command-line interface
Input validation
Win and draw detection
Simple and beginner-friendly code structure
🛠️ Technologies Used
Python 3

▶️ How to Run
Option 1 — Jupyter Notebook

Open the notebook:

Tic tac toe.ipynb
Run all cells.
Option 2 — VS Code / Terminal

If converted to a .py file:

python tic_tac_toe.py
🎯 Game Rules
The game is played on a 3×3 grid.
Player 1 uses X
Player 2 uses O
Players take turns choosing positions.
First player to align 3 symbols horizontally, vertically, or diagonally wins.
If all spaces are filled and nobody wins, the game ends in a draw.
